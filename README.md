# 书信簿 Epistolary · v0.20

SillyTavern 扩展。逐字保存 RP 里的每一封信，记下谁读过、听过、被转述过哪几段；聊天时按**当前角色实际知道的内容**把相关段落的原文注入给 AI。可以把信寄给角色，让角色在聊天里真实地收信、读信，再用自己的口吻写回信（真实历史人物会参照其现存书信的文风）。

---

## 安装

**方法一：从 GitHub 安装（推荐）**

酒馆 → 扩展（积木图标）→「安装扩展 / Install extension」→ 粘贴这个仓库的网址 → 安装 → 刷新页面。

以后更新：扩展 →「管理扩展 / Manage extensions」→ 找到「书信簿」→ 点更新，然后按 `Ctrl+Shift+R` 刷新。

**方法二：手动复制**

把整个文件夹复制到 `SillyTavern/data/default-user/extensions/` 下，刷新页面。

两种方法只用一种，不要同时装两份。

> 要求 SillyTavern 1.12 以上。在 1.19.0 上实际装过、完整走过一遍流程。

**在线演示**：开启 GitHub Pages 后，打开 `https://<你的用户名>.github.io/<仓库名>/` 就能在浏览器里（包括手机）预览界面和动画。演示页模拟了一个小酒馆，AI 回复是写死的演示文字，数据只存在当前浏览器里。演示页相关的文件（`demo.html`、`index.html`、`demo/`）不影响插件在酒馆里的运行。

## 简单模式与高级模式

面板右上角可以随时切换，扩展设置里也能改。两种模式用的是同一份数据，随时切换不会丢任何东西。

- **简单模式**（默认）：**存档信件 + 暗号**。每封信有一个暗号，比如【信1】。在聊天里写上暗号，那一轮 AI 才会读到这封信；不写就不注入。没有寄送、在途、转交、自动发现这些东西，右下角也不会弹信箱。
- **高级模式**：在暗号之外，还有寄送（信在路上走几天、按剧情日期或楼层送达）、托人转交、空壳信、剧情里自动发现收信、按“谁读过、谁知道”自动注入相关段落；写信页下面多出「其他属性 / 段落与关键词 / 流转记录 / 知情一览」，另外有「套语」和「注入预览」两页。

## 暗号

- 每封信保存时自动分到一个暗号：【信1】【信2】……也可以在写信页信头的「暗号」格里改成自己喜欢的，比如【星夜】（没写括号会自动加上【】）。暗号不能重复。
- 在聊天里写上暗号（**连括号一起**，比如“他把【信1】又读了一遍”）。发送的一瞬间、AI 开始写之前，书信簿会把这封信的**全文接在你这条消息后面**：

  ```
  他把【信1】又读了一遍。

  【信件 【信1】｜勒鲁 写给 文森特｜1890-06-27】

  （信的全文）

  【信件完】
  ```

  AI 读的就是你这条消息，所以一定看得到原文。聊天里这一段会**折叠**成一行“▸ ✉ 勒鲁写给文森特 的信 · 1890-06-27 【信1】”，点开能看全文，不会刷屏。刷新、换聊天回来也照样折叠。
- 不想改动你的消息：「设置 → 暗号怎么生效」选“只在生成时悄悄注入”，就和以前一样（但有些预设会把注入的内容挤掉）。
- 一条消息里可以写好几个暗号，就一起注入。换一个回复、重新生成时，还会带上（因为你那条消息没变）。
- 信件列表、阅读页里点一下暗号就能复制。
- 暗号在高级模式里也照样能用。
- 写对了暗号，发送后右上角会提示“✉ 这一轮把信交给了 AI”；写了 【信12】 这种档案里没有的暗号，会提醒你对不上。括号写成 [信1]、〖信1〗，数字写成全角“１”，也都认得；只写“信1”不带括号不算。
- 信的原文放在最新一条消息后面，并且明确告诉 AI：这封信已经写好了，读到的就是原文，不要另编、改写。想确认到底注入了什么，可以在浏览器控制台（F12）输入 `epistolary.last()`。

## 写给你的信：收到了才拆

角色在回复里给你写了一封信（比如回信），书信簿会**先把信藏起来，等剧情里你收到了再拆**：

1. **写的时候**：角色回复一写完，书信簿按格式认出“称呼是你”的信（不调用 AI），存进档案、分好暗号。聊天里**只把信的那几段藏起来**，换成一张小卡片“✉ 文森特写了一封给你的信，还没到你手里”；信前信后、信中间的旁白（“他停下笔，望着窗外”）照常显示。
2. **收到的时候**：之后剧情里写到你收到了——AI 的回复或思考里写“你收到了文森特的信”“邮差把一封信递给你”，或者你自己写“我收到了文森特的信”——右下角提示“📬 你收到了文森特的信 · 拆开”。写信和收到写在同一条回复里也行。
3. **拆开**：播放拆信动画 → 打开信纸 → 聊天里藏着的那几段才露出来。
4. 剧情里其实已经收到了、但书信簿没认出来：点卡片上的「已经收到了」直接拆。
5. 还没拆就刷新、换聊天再回来，信照样藏着。同一个人有好几封没收到的信时，一次只算收到最早的那一封。

几点说明：

- **得认得出是寄给你的**：信的称呼要对得上你在酒馆里的用户名，或者在「人物」页给自己建一个人物，把信里对你的各种称呼都写进别名。
- **“边想边写”**：信中间的旁白，整段包在 *星号* 或（括号）里的、信写在 > 引用里而旁白不在引用里的、或者是“他停下笔 / 顿了顿 / 蘸了蘸墨 / 又写道”这类第三人称写信动作的，都会自动去掉，不进信的正文，聊天里也照常显示。没有这些标记、纯叙述的旁白，按格式认不出来；这种情况用「从聊天记录找信」的「AI 识别」，AI 会把夹在中间的旁白挑出来去掉（正文仍然是从原文逐字截取的）。
- **“他收到了你的来信”不算你收到**：只有“你 / 我 / 你的名字”是收信的那个人才算。
- **流式输出**：一写到给你的称呼，那条消息会先模糊掉，写完再把信的部分藏起来；称呼之前的文字还是看得到。最保险是关掉流式输出。
- 不想要：「设置 → 显示」里取消“角色写给你的信：先藏起来，剧情里收到了再拆”。

## 写一封信

写信页像文档一样：

- **工具栏**：保存（也可以按 `Ctrl+S`）、寄出、让对方回信、翻译；插入称呼、开头语、结尾祝语、署名前的套语；插入按书信语言写好的**日期行**（例如 `Paris, le 10 juin 1889`、`巴黎，1890年11月3日`）；插入附言；「✦ 外观与款式」。
- **信头**：写信人、收信人、写信日期、寄出地、寄往地、书信语言（鼠标停在每一项上有说明）。新信件会自动填上你的名字、当前角色和剧情日期。
- **信纸**：直接在上面写。**空一行就是新的一段**。

「语言」这一栏会影响套语和日期行的写法，也会影响回信用什么语言写。常见写法：

- 留空：中文信
- `法语（中文显示）`：人物之间实际用法语通信，但信用中文写出，保留法语书信的称呼、日期写法和结尾习惯，不会冒出“见字如晤”“此致敬礼”这种中文套语
- `英语`：直接用英语写

### 写信时的字号

写信页顶部的「编辑字号 A− / A+」只调你写信时看到的字有多大（50%–160%，默认 90%），不改这封信本身的字号；预览、阅读页、信封动画仍然按「外观与款式」里的字号显示。也可以在「设置 → 显示 → 写信时的字号」里改。

### 预览与动画回放

写信页顶部的「👁 预览」：不用保存，直接看这封信写好以后在信纸上的样子——手写随机感、花体、字号、纸张磨损、随信附上的东西都和阅读页一样。预览里还有：

- **▶ 封缄动画**：信纸折好、装进信封、封口、飞走，就是寄信时的那段。
- **▶ 拆信动画**：收信时拆开信封、取出信纸的那段。

可以反复播放，换了外观（纸、墨水、信封、火漆）以后再看一遍效果。点「继续写」回到写信页，什么都不会被保存或寄出。

### 随信附上

写信页信纸下面有「📎 随信附上」，专门记信里夹带的东西：💰 钱、✏️ 速写 / 画、📷 照片、🌸 压花 / 树叶、🎁 礼物 / 小物件、📄 附页 / 剪报 / 票据、✉️ 另一封信、📎 其他。

- 每件记：是什么（“五枚二十法郎金币”）、金额（钱才有，“100 法郎”）、样子 / 细节（“用亚麻布包着”）。“另一封信”可以直接选档案里的某封信。
- **从正文里找**：正文里写了“随信附上……”“另附……”“夹着……”“I enclose……”“ci-joint……”，点一下就能记下来，名字和金额再改改就行。「✨ AI 填写」也会顺手把这些填上。
- 阅读页信纸下面会列出随信附上的东西；“另一封信”可以点开看。
- **AI 会知道**：收信人读信、用暗号注入这封信时，AI 会被告知“拆信时还会一起拿出来：……”，可以写收信人对金币、速写的反应。托人转交时，转交人没拆信也摸得出来：“信封沉甸甸的，捏得出里面有硬币一类的东西”。
- 从聊天记录导入的信，也会自动认出“随信附上……”。

### 信头不用自己填

写信人、收信人、写信日期、寄出地、寄往地、书信语言，都可以交给 AI：

- **写新信时自动填**：先按你的人设名、当前角色、剧情日期，以及你们之前通信用过的地点和语言填上，再让 AI 读最近的剧情补全和修正。AI 填的格子会**标黄**，直接改就行；你自己改过的格子，AI 不会再动。
- **写完正文再点「✨ AI 填写」**：正文里的称呼、署名、日期行最可信，AI 会照着它们改。
- **AI 还会估算信在路上要走几天**（按时代、两地距离和交通方式），寄信时的送达日期会按这个预先算好。
- 寄信时信头还有空着的，会先自动补一次。
- 不想自动填：「设置 → 显示」里取消“写新信时让 AI 自动填信头”。
## 字迹

选的是“这个人的字写成什么样”，不是字体文件。插件会按纸上写的文字自动挑字体：

| 字迹 | 英文 / 法文 | 中文 | 适合 |
|---|---|---|---|
| 端正 | EB Garamond | 思源宋体 | 正式通信、档案、公函 |
| 自然（默认） | Allura | 霞鹜文楷 | 普通私人信件 |
| 优雅 | Great Vibes | 马善政楷书 | 贺信、请柬；不适合长信 |
| 随意 | Caveat | 霞鹜文楷 | 便条、草稿、匆匆写的短信 |
| 打字机 | Courier | 仿宋 | 打字机、电报 |

- 在「人物」页给每个人设好**字迹**，这个人写信（包括 AI 代写的回信）就默认用它。每个人物的信会有不同的“笔迹”。
- **✍ 花体称呼署名**：阅读时把开头的称呼和结尾的署名换成花体（Great Vibes / 马善政），正文保持原来的字迹。这是很多讲究的信的写法，比整封都用花体好读。
- 纸上写的是英文或法文时，手写体会自动放大一些，和中文一样好读；法文的 é è ê ë à â ç î ï ô œ ù û ü ÿ 都检查过。
- 书信语言写成“法语（中文显示）”时，纸上实际是中文，会用中文字体。
- 阅读时，第一行的地点日期自动靠右，结尾的署名自动靠右，附言单独排。

**字体从哪来**：四套英文/法文字体随插件附带（约 400KB，`fonts/` 目录，SIL OFL 1.1 授权），离线也能用。中文字体体积很大，不打包，打开酒馆时从 jsDelivr 按需加载：字体被切成很多小片，只下载信里用到的字，下载过的会被浏览器缓存。不想联网可以在扩展设置里关掉「在线加载中文书信字体」，这时用电脑自带的楷体和宋体。

### 选项的含义

纸、墨水、封缄、信封在不同时代和文化里各有讲究，收信人（AI）会按这些来理解。「✦ 外观与款式」里每个选项下面都写着它的含义；容易被误读的标 **⚠**，寄出前还会再提醒一次：

- **黑色火漆**：用于讣告、吊唁和服丧期间的通信。收信人一看到黑色封口，会以为有人去世了。（款式包里只有「讣告 · 吊唁信」用它。）
- **红墨水（酒红）**：中文书信里用红笔写信有“绝交”或不吉利的意思；西方常被理解为急事或带着火气。
- **航空信封、淡蓝航空信纸**：航空邮件 1918 年前后才出现，更早的故事里用会显得穿越。
- **打字机**：1874 年才上市，私人信件用它显得公事公办。

这些说法多来自 19 世纪欧洲的书信礼仪和中文书信习惯，各地不完全一样。

### 字号

「✦ 外观与款式 → 字」里可以选字号：小（字小而密）、标准、大、特大。整张纸一起缩放，横格信笺的格线也跟着变，写信、阅读、信封动画里都一样。

外文信（书信语言是法语、英语等）里夹着中文时，比如每句后面括号里的翻译：外文手写体为了看得清会放大，中文**不跟着放大**，保持正常大小；还觉得大，在「✦ 外观与款式 → 字 → 中文字号」里选“小”或“很小（像旁注）”。这个选项只在书信语言是外文时出现。

### AI 能“看到”信的样子吗

能。角色收信、读信时，书信簿除了给 AI 信的全文，还会告诉它这封信看上去、摸上去是什么样，例如：

> 信封：牛皮纸信封，封口压着朱红的“缄”字印。
> 信纸：泛黄的旧纸，对折了一次，纸已经旧了，有折痕和淡淡的污渍；墨色已经褪成了褐色，字写得潦草随意，像是匆匆写就，笔画发抖、歪歪斜斜；字写得很小、很密。

AI 会挑一两处自然地带进反应里，比如从发抖的字迹看出写信人病了。托人转交时，转交人拆开之前只知道信封的样子，拆开以后才看到信纸和字迹。不想告诉 AI：「设置 → 显示」里取消“读信时把信的样子告诉 AI”。
## 款式包、纸张磨损、手写随机感

写信页工具栏里的 **✦ 外观与款式**（版式、纸张、磨损、字迹、墨水、笔迹抖动、花体、信封、封缄都在这里，每一项都有说明）：

- **一键套用整套外观**（只改样子，不动正文）：

  | 款式 | 样子 |
  |---|---|
  | 1890 法国私人信 | 奶油棉纸、蓝黑墨水、自然手写、朱红火漆、花体称呼署名 |
  | 维多利亚英国 | 素白信纸、黑墨、端正字迹、白信封配黑火漆 |
  | 民国家书 | 红线信笺、自然手写、牛皮纸信封、盖朱印“缄”字 |
  | 战地家书 | 粗糙的白纸、潦草的字、褪色墨水、胶封、纸已经旧了 |
  | 航空信 | 淡蓝薄信纸、横版平放、红蓝边航空信封 |
  | 公函 / 打字机 | 打字机字体、白信封、不封火漆 |
  | 奇幻羊皮纸 | 泛黄破损的旧纸、深褐墨水、金色火漆 |

- **把当前样子存为我的款式**：自己调好的一套外观可以存下来，以后一键套用。
- **纸张磨损**：崭新 / 轻微 / 旧信 / 破损。纸边会被“咬”出不规则的毛边，纸面有淡淡的污渍和斑点（用浏览器的 SVG 滤镜实时生成，不用图片；只作用在纸上，字不会糊）。横格、红线信笺的格线不会被扭曲。
- **笔迹抖动**：无 / 轻 / 中 / 重。每个字（中文）或每个词（英文、法文，因为手写体字母是连笔的）都有极轻微的旋转、上下浮动和墨色深浅；钢笔字还会越写越淡、过十来个字“重新蘸一次墨”；打字机字体则是色带深浅不匀。
  - 用信件编号当种子：**同一封信每次打开都长得一样**，不会一刷新就变。
  - 在「人物」页给每个人设“笔迹抖动”，字写得稳的人和潦草的人一眼就能看出来。信件上单独设置的会优先。
  - 只在阅读和信封动画里显示；写信时是普通文字，方便编辑。
  - 扩展设置里可以整个关掉。

**墨水**：墨黑、蓝黑、深蓝、深褐、酒红、墨绿、褪色铁胆，也可以选「自定义颜色」用取色器挑。墨色和纸色对比度不够时，对话框和写信页会提醒。写信时的文字一律用墨色显示，不受酒馆主题里输入框颜色的影响。

封缄方式新增 **朱印“缄”**（中式信件：一方红印盖在封口接缝上）和 **不封（胶封）**；信封新增 **航空信封**；信纸新增 **红线信笺**。

## 横版与竖版信纸

工具栏里选「竖版（对折入封）」或「横版（平放入封）」，默认竖版。

- **写信页和阅读页**：竖版像一张竖放的 A4，横版像横放的，字多了纸会往下长。
- **竖版**：阅读时纸中间有一道淡淡的折痕。寄出时，信纸先在信封前展开，下半张沿中线折上来，折好后从上方插进信封；拆信时抽出来，拿到面前再展开。屏幕较矮时镜头会自动拉远，保证整张纸都在画面里。
- **横版**：平放着直接滑进信封。
- 横格信笺上，每一行字都会压在格线上。

## 寄出：信要在路上走一段时间

写好后点「✉ 寄出」，选送达方式：

- **按剧情日期送达**（推荐）：填一个送达日期（有 +1 天、+3 天、+1 周、+2 周的快捷按钮）。故事里到了这一天，信才送到。
- **按聊天楼层送达**：再聊 N 层后送到。故事里没有明确日期时用这个。
- **立即送达**：不等了，现在就送到。

信在路上的时候，你这边的剧情照常继续。**收信人在信送到之前不会知道信的内容**（插件不会把它注入给收信人）。

**剧情日期怎么往前走**：有在途的信时，插件每隔几层（默认 6 层，在「设置」里改）让 AI 根据最近的对话推算故事里现在是哪一天，比如对话里写了“第二天”“过了一周”。日期只会往后走，不会因为回忆、倒叙倒退。也可以在「设置」里手动改，或者点「让 AI 推算」。

**信到了**：右下角会出现一个小信箱：

- 寄给角色的信：「📬 文森特 收到了 E. 的信」→ **切过去看收信反应**：镜头切到收信人那边（会播放拆信动画），聊天里只发一句旁白，信的原文直接交给 AI（不发进聊天），AI 描写收信人收信、读信的样子和真实反应（对信里具体的句子有反应，不会复述整封信，也不会马上写出完整回信）。看完以后，信箱里有「↩ 回到 E. 这边」（插入一句旁白，镜头回到写信人）和「让 文森特 写回信」。
- 寄给你的信（比如角色的回信）：「📬 你收到了 文森特 的回信」→ **拆开看**（拆信动画 + 阅读页），或者**放进聊天**。
- 「📮 在途 N 封」可以展开看每封信还要多久，也可以点「现在送达」。

在「设置」里勾上“信到了就自动切过去”，就不用每次点了。

> 为什么不放进世界书：世界书条目只要关键词命中，任何角色都能看到，信还在路上收信人就“知道”了内容。书信簿把在途的信存在自己的档案里，按“谁在什么时候收到”来决定谁能知道，所以不用世界书。

## 托人转交

寄信对话框里展开「🤝 托人转交（可选）」，填上**转交人**，再填转交人拿到信以后、还要走几天（按楼层送达时是几层）才能送到收信人手里。

信会先送到转交人手里。**之后拆不拆、看不看、交不交，都只由转交人决定**：

- **转交人是角色**：信到了以后，信箱里点「切过去看 TA 怎么处理」。聊天里只出现一段旁白——转交人收到了一封封好的信、信封上写着给谁——**不会给出信的内容**，AI 只会被提醒“信是封着的，你不知道里面写了什么，拆不拆、交不交由你自己决定”。
  - 角色写完这段剧情后，书信簿会让 AI 读最近几层（包括思考过程），判断转交人拆没拆、打算怎么办，然后照办。**没有“手动决定”**：角色在剧情里怎么做，信就怎么走。
  - **拆开了**：下一次生成时把信的原文直接交给 AI（不发进聊天），让转交人读这封不是写给 TA 的信（对信里的句子有反应，然后决定还交不交）。从这一刻起，转交人才“知道”信的内容。
  - **转交**：重新封好、在信封上写了给收信人的话、交给送信人，都算。信开始走第二段路，到时间后收信人收到。
    - 偷偷拆了又没封好：收信人读信时 AI 会被告知“封口有被拆开过的痕迹”。
    - 光明正大地拆阅（比如有写信人授权、换上自己的火漆、在信封上注明拆阅过）：收信人那边会知道是谁拆阅的，信封上写的话也会原样告诉 AI。
  - **先留着** / **不转交**：信压在转交人手里，收信人收不到，直到剧情里转交人改主意。
  - **还没决定**：拆开以后还没决定的，书信簿**每一层都会再看一次**，剧情里一写到 TA 的决定就照办。
- **转交人是你**：信箱里会出现「X 托你把一封信转交给 Y」，你自己选「拆开看」「转交给 Y…」「先留着」「不转交」。拆开的话会播放拆信动画、打开阅读页；转交时可以勾「拆过的信重新封好了」。

知情记录会跟着走：转交人收到时只记“知道有这封信”，拆看后记“读过全文”，收信人只有在信真正送到时才知道内容。高级模式的「流转记录」里能看到每一步（托 X 转交、代为转交、转交前私自拆看、转交、扣下没有转交）。

收下角色的回信时也可以托人转交。

**转交期限**：按剧情日期送达时，可以填“希望收信人最晚哪天收到”。书信簿会算出转交人**最晚哪天要看完、转交出去**（= 希望收到的日子 − 转交后路上的天数），在寄信对话框里显示整条时间线；来不及的话会直接告诉你。进入**转交倒数**（离最晚转交日只剩一天）以后，剧情日期改成每层推算一次，转交人的动静也每层判断一次；到了期限前一天转交人还没处理，会弹提醒；过了期限，信箱里会标红。同样，在途的信**离送达只剩一天**时，剧情日期也是每层推算一次，不会错过送达。按楼层送达时，转交人拿着信超过 4 层没处理也会提醒。

**不用切过去也行**：转交人是当前角色时（名字写法不同也认得，比如档案里叫“提奥梵高”、剧情里写“提奥”），只要角色的回复（包括思考过程）或你自己的消息里写到 TA 在动这封信（拆信、看信、转交、把信收起来……），书信簿就让 AI 判断 TA 做了什么并照办。写到拆开时，原文会马上交给 AI。

## 剧情里自己写到收信

不点信箱的按钮也可以：书信簿会读每一条新消息，**包括 AI 的思考过程**。只要写到**收信人的名字 + 收信的说法**（收到信、来信、拆开信、读信、letter……），并且信已经送到、或者文字里写的日期就是送达日期，或者剧情日期已经过了送达日期，就会：

- 角色的回复里写到：下一次生成时，把信的原文直接交给 AI，让角色接着写读信的反应。
- 你自己的消息里写到：这一轮生成就把原文交给 AI。

**信的原文不会发进聊天**，只在那一次生成时直接注入给 AI（换一个回复、重新生成时也会带上），聊天记录不会被一封封原文撑得很长。右下角信箱会显示“📖 下一次生成时，某某会读到某某的信”，可以点「看原文」。读完以后，信里的内容按知情记录照常注入：聊到相关的事，读过的人能想起相关段落。

另外，每次生成前都会提醒 AI：哪些信已经送到但还没读、哪些信压在转交人手里——如果剧情写到拆信，只写到拆开为止，**不要自己编信的内容**，原文会另外给出。

不想要这些自动处理：「设置 → 显示」里取消“剧情里写到收信、拆信时，自动把信的原文交给 AI”。

## 封缄与拆信动画

- **寄出时**：信纸滑进信封 → 翻盖合上并轻轻回弹 → 滴上火漆 → 印章从上方落下、压实、抬起，火漆上留下写信人的首字 → 信封翻到正面，盖上邮戳 → 飞走（只存档时原地淡出）。
- **收信时**（AI 写好回信时，以及第一次打开寄给你的信时）：信封沿弧线飞进来，正面是地址和邮戳 → 翻到背面 → 火漆裂成两半掉落 → 翻盖弹开 → 信纸升起，迎面展开。

信封（象牙白、牛皮纸、淡蓝、白、航空信封）和封缄方式（朱红、藏青、墨绿、黑、金色火漆，朱印“缄”，或不封）在写信页工具栏里选；信纸、墨水、字迹、版式也会用在信封动画里。

点画面任意处可以跳过。扩展设置里可以关掉动画；系统开启了“减少动态效果”时不会播放。

这是用 CSS 3D 搭的真实三维场景，不是视频，不依赖任何外部库，手机上也能流畅播放。动画的分镜思路参考了 Justin Levine 的 *Contact Envelope*，代码是另写的。

## 让角色回信

在写信页点「↩ 让对方回信」，或者在阅读视图里点「↩ 让 某某 回信」。可以设置回信日期（默认是收到后两天）和篇幅。

AI 写回信时会拿到：

- 来信全文，分段编号，方便它提起具体的话
- 两人此前的往来信件（最近三封）
- 回信人以前写给别人的信，用来参考口吻
- 回信人的**文风档案**（见下一节）
- 一组“像真的回信”的要求：不逐条答复，先回应最打动自己的事；会写自己的近况；会提起来信里的原话，也可能误解或回避；遵守当时的书信格式；只知道自己经历过的事
- 书信语言和格式要求

如果回信人就是当前聊天的角色，还会带上角色卡设定和最近的聊天一起写。

写好的回信会作为草稿打开，你可以直接改。然后：

- **✓ 收下这封回信**：保存，并自动记录回信的寄出和送达（路上的天数沿用来信的天数）；可以顺便发到聊天里，作为角色的消息
- **↻ 重新写**
- **丢弃**

你自己回复角色的来信时，在阅读视图里点「✎ 回复这封信」。

## 翻译

写信页的「🌐 翻译」：比如先用中文写草稿，再译成法语寄出去。

- 可以选目标语言（法语、英语、德语、意大利语、西班牙语、俄语、荷兰语、日语、中文，或者自己填）和文风：
  - **按写信年代的书信体**：参考写信日期，用那个年代的称呼、客套语和结尾。
  - 现代自然的说法。
  - 尽量保持原文的语气和句式。
- 段落保持一一对应。译文出来以后可以直接改，然后：
  - **替换正文**：原文会挪到这封信的备注里，书信语言自动改成目标语言。
  - **另存为译本**：原信不动，另存一封“译本”。

阅读外文信时，阅读页有「🌐 中文译文」，翻译给你看，不改原信；译文会缓存，下次直接显示。

## 从聊天记录找信

信件列表里的「📥 从聊天记录找信」：把当前聊天里已经写出来的信（比如角色在回复里写的一封信）逐字存进档案。

- **按格式识别**：找“称呼……结尾/署名”这样的段落，快，不调用 AI。会去掉引用符号 `>` 和斜体星号，不会把前后的叙述带进去。
- **AI 识别**：格式比较随意的信用这个。AI 只负责指出每封信从哪句开始、到哪句结束，**正文一律从聊天原文逐字截取**，AI 改写过的内容不会进档案；对不上原文的会被丢掉。
- 找到的信会列出来，可以改写信人、收信人、日期；档案里已经有的会标出来、默认不勾。
- 导入时可以记为“收信人已读”，这样他们会“记得”信里的内容。

### 空壳信

剧情里已经有了、但正文还没写出来的信，比如“他写了五封信，封好交给提奥，每月月底寄一封”。在「方法」里选 **找空壳信**，AI 会找出这些信（一次提到几封就列几封），并填好：写信人、收信人、信封上写的字、现在在谁手里、该哪天送到、谁已经读过。确认后建成“空壳信”：

- 信件列表里标着「📄 空壳 · 待写正文」，点「编辑」就能写正文；保存后，寄送状态（在谁手里、哪天送到）不变。
- 在转交人 / 保管人手里的，会照常算转交期限、提醒、判断 TA 拆没拆、交不交。同一个人手里有好几封时，会逐封判断，拆了一封不会算成几封都拆了。
- 正文写好之前，剧情里有人拆开它，AI 只会写到拆开为止，**不会自己编内容**；信箱里会提示“空壳信，正文还没写”，点「写正文」写完，下一次生成就会读到。

## AI 接口

「⚙ 设置」→「AI 接口」。写回信、翻译、生成关键词、识别聊天里的信、推算剧情日期，都用这里设置的接口，可以和聊天用的 API 分开（比如聊天用好的模型，这些杂事用便宜的模型）。

- **跟随酒馆当前的 API**（默认）。
- **使用酒馆的连接配置**：先在酒馆的“API 连接”里设好一套接口并保存为连接配置，这里选它。不会切换你正在聊天用的接口。
- **自定义接口（OpenAI 兼容）**：填地址、密钥、模型（DeepSeek、硅基流动、OpenRouter、本地 Ollama 等都行），可以「获取模型列表」「测试连接」。请求经由酒馆服务端转发，不会有浏览器跨域问题。密钥保存在酒馆的设置文件里。

回信人就是当前聊天的角色时，写回信会带上角色卡设定和最近的剧情。

## 人物与文风档案

在「人物」页：

- **别名**：同一个人的不同叫法。角色卡叫「Vincent」、信里写「文森特」的话，一定要写成同一个人的别名，否则插件会认为这个角色什么信都没读过。
- **真实历史人物**：勾上之后，AI 会参照此人现存书信的口吻来写，同时被要求不要编造“名言”，也不要冒充真实信件里的原句。
- **参考的书信集**：比如“梵高书信（致提奥）”。
- **文风要点**：怎么称呼对方、怎么结尾、句子长短、常谈什么、对不同的人口吻有什么不同。
- **书信样本**：粘贴此人真实书信的片段，多段之间用单独一行 `---` 隔开。每次写回信时会随机挑几段给 AI 参考口吻，并提醒它只模仿口吻、不照抄内容。

「载入示例：文森特·梵高」会添加一份梵高的文风要点。这份要点是根据梵高书信公认的特点概括的，不含书信原文。想让回信更像本人，可以在「书信样本」里粘贴几段你手头的梵高书信。样本只保存在你自己的档案里。

## 聊天时自动注入信件

每次生成回复前，插件会扫描最近几条消息里的关键词，找出相关的信件段落，再按**视角角色**（默认是当前发言的角色，群聊时自动切换）和**剧情日期**过滤：

| 视角角色对这一段的了解 | AI 会看到 |
|---|---|
| 是写信人，或读过、听人念过、抄录过 | 这一段的**逐字原文** |
| 听人转述过 | 这一段的**一句话大意**（没有大意时，退化成下一行） |
| 只知道信存在 / 收到了还没读 | 一句「知道有这封信，但不知道内容」 |
| 没有任何记录 | **什么都没有** |

注入的文本会写明「信中所写是写信人当时的说法，不一定是事实」。正在聊天里被读的那封信不会被重复注入。

高级模式的「注入预览」能看到这一轮会注入什么、为什么命中、哪些被挡住以及原因。

# 书信簿 Epistolary · v0.7

SillyTavern 扩展。逐字保存 RP 里的每一封信，记下谁读过、听过、被转述过哪几段；聊天时按**当前角色实际知道的内容**把相关段落的原文注入给 AI。可以把信寄给角色，让角色在聊天里真实地收信、读信，再用自己的口吻写回信（真实历史人物会参照其现存书信的文风）。

---

## 安装

**方法一：从 GitHub 安装（推荐）**

酒馆 → 扩展（积木图标）→「安装扩展 / Install extension」→ 粘贴这个仓库的网址 → 安装 → 刷新页面。

以后更新：扩展 →「管理扩展 / Manage extensions」→ 找到「书信簿」→ 点更新，然后按 `Ctrl+Shift+R` 刷新。

**方法二：手动复制**

把整个文件夹复制到 `SillyTavern/data/default-user/extensions/` 下，刷新页面。

两种方法只用一种，不要同时装两份。

> 要求 SillyTavern 1.12 以上。在 1.19.0 上实际装过、完整走过一遍流程。

**在线演示**：开启 GitHub Pages 后，打开 `https://<你的用户名>.github.io/<仓库名>/` 就能在浏览器里（包括手机）预览界面和动画。演示页模拟了一个小酒馆，AI 回复是写死的演示文字，数据只存在当前浏览器里。演示页相关的文件（`demo.html`、`index.html`、`demo/`）不影响插件在酒馆里的运行。

## 简单模式与专家模式

面板右上角可以随时切换，扩展设置里也能改。

- **简单模式**（默认）：只有「信件 / 写信 / 人物」三页。写信页就是一张信纸，保存时自动让 AI 给每段生成检索关键词，寄出时自动记录送达和阅读。
- **专家模式**：写信页下面多出「其他属性 / 段落与关键词 / 流转记录 / 知情一览」四个折叠块，另外有「套语」和「注入预览」两页。

两种模式用的是同一份数据，随时切换不会丢任何东西。

## 写一封信

写信页像文档一样：

- **工具栏**：保存（也可以按 `Ctrl+S`）、寄出、让对方回信、翻译；插入称呼、开头语、结尾祝语、署名前的套语；插入按书信语言写好的**日期行**（例如 `Paris, le 10 juin 1889`、`巴黎，1890年11月3日`）；插入附言；「✦ 外观与款式」。
- **信头**：写信人、收信人、写信日期、寄出地、寄往地、书信语言（鼠标停在每一项上有说明）。新信件会自动填上你的名字、当前角色和剧情日期。
- **信纸**：直接在上面写。**空一行就是新的一段**。

「语言」这一栏会影响套语和日期行的写法，也会影响回信用什么语言写。常见写法：

- 留空：中文信
- `法语（中文显示）`：人物之间实际用法语通信，但信用中文写出，保留法语书信的称呼、日期写法和结尾习惯，不会冒出“见字如晤”“此致敬礼”这种中文套语
- `英语`：直接用英语写

## 字迹

选的是“这个人的字写成什么样”，不是字体文件。插件会按纸上写的文字自动挑字体：

| 字迹 | 英文 / 法文 | 中文 | 适合 |
|---|---|---|---|
| 端正 | EB Garamond | 思源宋体 | 正式通信、档案、公函 |
| 自然（默认） | Allura | 霞鹜文楷 | 普通私人信件 |
| 优雅 | Great Vibes | 马善政楷书 | 贺信、请柬；不适合长信 |
| 随意 | Caveat | 霞鹜文楷 | 便条、草稿、匆匆写的短信 |
| 打字机 | Courier | 仿宋 | 打字机、电报 |

- 在「人物」页给每个人设好**字迹**，这个人写信（包括 AI 代写的回信）就默认用它。每个人物的信会有不同的“笔迹”。
- **✍ 花体称呼署名**：阅读时把开头的称呼和结尾的署名换成花体（Great Vibes / 马善政），正文保持原来的字迹。这是很多讲究的信的写法，比整封都用花体好读。
- 纸上写的是英文或法文时，手写体会自动放大一些，和中文一样好读；法文的 é è ê ë à â ç î ï ô œ ù û ü ÿ 都检查过。
- 书信语言写成“法语（中文显示）”时，纸上实际是中文，会用中文字体。
- 阅读时，第一行的地点日期自动靠右，结尾的署名自动靠右，附言单独排。

**字体从哪来**：四套英文/法文字体随插件附带（约 400KB，`fonts/` 目录，SIL OFL 1.1 授权），离线也能用。中文字体体积很大，不打包，打开酒馆时从 jsDelivr 按需加载：字体被切成很多小片，只下载信里用到的字，下载过的会被浏览器缓存。不想联网可以在扩展设置里关掉「在线加载中文书信字体」，这时用电脑自带的楷体和宋体。

## 款式包、纸张磨损、手写随机感

写信页工具栏里的 **✦ 外观与款式**（版式、纸张、磨损、字迹、墨水、笔迹抖动、花体、信封、封缄都在这里，每一项都有说明）：

- **一键套用整套外观**（只改样子，不动正文）：

  | 款式 | 样子 |
  |---|---|
  | 1890 法国私人信 | 奶油棉纸、蓝黑墨水、自然手写、朱红火漆、花体称呼署名 |
  | 维多利亚英国 | 素白信纸、黑墨、端正字迹、白信封配黑火漆 |
  | 民国家书 | 红线信笺、自然手写、牛皮纸信封、盖朱印“缄”字 |
  | 战地家书 | 粗糙的白纸、潦草的字、褪色墨水、胶封、纸已经旧了 |
  | 航空信 | 淡蓝薄信纸、横版平放、红蓝边航空信封 |
  | 公函 / 打字机 | 打字机字体、白信封、不封火漆 |
  | 奇幻羊皮纸 | 泛黄破损的旧纸、深褐墨水、金色火漆 |

- **把当前样子存为我的款式**：自己调好的一套外观可以存下来，以后一键套用。
- **纸张磨损**：崭新 / 轻微 / 旧信 / 破损。纸边会被“咬”出不规则的毛边，纸面有淡淡的污渍和斑点（用浏览器的 SVG 滤镜实时生成，不用图片；只作用在纸上，字不会糊）。横格、红线信笺的格线不会被扭曲。
- **笔迹抖动**：无 / 轻 / 中 / 重。每个字（中文）或每个词（英文、法文，因为手写体字母是连笔的）都有极轻微的旋转、上下浮动和墨色深浅；钢笔字还会越写越淡、过十来个字“重新蘸一次墨”；打字机字体则是色带深浅不匀。
  - 用信件编号当种子：**同一封信每次打开都长得一样**，不会一刷新就变。
  - 在「人物」页给每个人设“笔迹抖动”，字写得稳的人和潦草的人一眼就能看出来。信件上单独设置的会优先。
  - 只在阅读和信封动画里显示；写信时是普通文字，方便编辑。
  - 扩展设置里可以整个关掉。

**墨水**：墨黑、蓝黑、深蓝、深褐、酒红、墨绿、褪色铁胆，也可以选「自定义颜色」用取色器挑。墨色和纸色对比度不够时，对话框和写信页会提醒。写信时的文字一律用墨色显示，不受酒馆主题里输入框颜色的影响。

封缄方式新增 **朱印“缄”**（中式信件：一方红印盖在封口接缝上）和 **不封（胶封）**；信封新增 **航空信封**；信纸新增 **红线信笺**。

## 横版与竖版信纸

工具栏里选「竖版（对折入封）」或「横版（平放入封）」，默认竖版。

- **写信页和阅读页**：竖版像一张竖放的 A4，横版像横放的，字多了纸会往下长。
- **竖版**：阅读时纸中间有一道淡淡的折痕。寄出时，信纸先在信封前展开，下半张沿中线折上来，折好后从上方插进信封；拆信时抽出来，拿到面前再展开。屏幕较矮时镜头会自动拉远，保证整张纸都在画面里。
- **横版**：平放着直接滑进信封。
- 横格信笺上，每一行字都会压在格线上。

## 寄出：信要在路上走一段时间

写好后点「✉ 寄出」，选送达方式：

- **按剧情日期送达**（推荐）：填一个送达日期（有 +1 天、+3 天、+1 周、+2 周的快捷按钮）。故事里到了这一天，信才送到。
- **按聊天楼层送达**：再聊 N 层后送到。故事里没有明确日期时用这个。
- **立即送达**：不等了，现在就送到。

信在路上的时候，你这边的剧情照常继续。**收信人在信送到之前不会知道信的内容**（插件不会把它注入给收信人）。

**剧情日期怎么往前走**：有在途的信时，插件每隔几层（默认 6 层，在「设置」里改）让 AI 根据最近的对话推算故事里现在是哪一天，比如对话里写了“第二天”“过了一周”。日期只会往后走，不会因为回忆、倒叙倒退。也可以在「设置」里手动改，或者点「让 AI 推算」。

**信到了**：右下角会出现一个小信箱：

- 寄给角色的信：「📬 文森特 收到了 E. 的信」→ **切过去看收信反应**：镜头切到收信人那边（会播放拆信动画），一段旁白加上信的全文发进聊天，AI 描写收信人收信、读信的样子和真实反应（对信里具体的句子有反应，不会复述整封信，也不会马上写出完整回信）。看完以后，信箱里有「↩ 回到 E. 这边」（插入一句旁白，镜头回到写信人）和「让 文森特 写回信」。
- 寄给你的信（比如角色的回信）：「📬 你收到了 文森特 的回信」→ **拆开看**（拆信动画 + 阅读页），或者**放进聊天**。
- 「📮 在途 N 封」可以展开看每封信还要多久，也可以点「现在送达」。

在「设置」里勾上“信到了就自动切过去”，就不用每次点了。

> 为什么不放进世界书：世界书条目只要关键词命中，任何角色都能看到，信还在路上收信人就“知道”了内容。书信簿把在途的信存在自己的档案里，按“谁在什么时候收到”来决定谁能知道，所以不用世界书。

## 托人转交

寄信对话框里展开「🤝 托人转交（可选）」，填上**转交人**，再填转交人拿到信以后、还要走几天（按楼层送达时是几层）才能送到收信人手里。

信会先送到转交人手里。**之后拆不拆、看不看、交不交，都只由转交人决定**：

- **转交人是角色**：信到了以后，信箱里点「切过去看 TA 怎么处理」。聊天里只出现一段旁白——转交人收到了一封封好的信、信封上写着给谁——**不会给出信的内容**，AI 只会被提醒“信是封着的，你不知道里面写了什么，拆不拆、交不交由你自己决定”。
  - 角色写完这段剧情后，书信簿会让 AI 读一遍，判断转交人拆没拆、打算怎么办，然后照办：
  - **拆开了**：把信的原文发进聊天，让转交人读这封不是写给 TA 的信（对信里的句子有反应，然后决定还交不交）。从这一刻起，转交人才“知道”信的内容。
  - **转交**：信开始走第二段路，到时间后收信人收到。如果拆过又没封好，收信人读信时 AI 会被告知“封口有被拆开过的痕迹”。
  - **先留着** / **不转交**：信压在转交人手里，收信人永远收不到，直到转交人改主意（信件列表和信箱里有「让 TA 转交」）。
  - 不想让判断自动生效，在「设置 → 寄信与送达」里取消“转交人在剧情里的决定自动生效”，信箱里会显示判断结果，由你点「照这样办」或手动选。
- **转交人是你**：信箱里会出现「X 托你把一封信转交给 Y」，你自己选「拆开看」「转交给 Y…」「先留着」「不转交」。拆开的话会播放拆信动画、打开阅读页；转交时可以勾「拆过的信重新封好了」。

知情记录会跟着走：转交人收到时只记“知道有这封信”，拆看后记“读过全文”，收信人只有在信真正送到时才知道内容。专家模式的「流转记录」里能看到每一步（托 X 转交、代为转交、转交前私自拆看、转交、扣下没有转交）。

收下角色的回信时也可以托人转交。

## 封缄与拆信动画

- **寄出时**：信纸滑进信封 → 翻盖合上并轻轻回弹 → 滴上火漆 → 印章从上方落下、压实、抬起，火漆上留下写信人的首字 → 信封翻到正面，盖上邮戳 → 飞走（只存档时原地淡出）。
- **收信时**（AI 写好回信时，以及第一次打开寄给你的信时）：信封沿弧线飞进来，正面是地址和邮戳 → 翻到背面 → 火漆裂成两半掉落 → 翻盖弹开 → 信纸升起，迎面展开。

信封（象牙白、牛皮纸、淡蓝、白、航空信封）和封缄方式（朱红、藏青、墨绿、黑、金色火漆，朱印“缄”，或不封）在写信页工具栏里选；信纸、墨水、字迹、版式也会用在信封动画里。

点画面任意处可以跳过。扩展设置里可以关掉动画；系统开启了“减少动态效果”时不会播放。

这是用 CSS 3D 搭的真实三维场景，不是视频，不依赖任何外部库，手机上也能流畅播放。动画的分镜思路参考了 Justin Levine 的 *Contact Envelope*，代码是另写的。

## 让角色回信

在写信页点「↩ 让对方回信」，或者在阅读视图里点「↩ 让 某某 回信」。可以设置回信日期（默认是收到后两天）和篇幅。

AI 写回信时会拿到：

- 来信全文，分段编号，方便它提起具体的话
- 两人此前的往来信件（最近三封）
- 回信人以前写给别人的信，用来参考口吻
- 回信人的**文风档案**（见下一节）
- 一组“像真的回信”的要求：不逐条答复，先回应最打动自己的事；会写自己的近况；会提起来信里的原话，也可能误解或回避；遵守当时的书信格式；只知道自己经历过的事
- 书信语言和格式要求

如果回信人就是当前聊天的角色，还会带上角色卡设定和最近的聊天一起写。

写好的回信会作为草稿打开，你可以直接改。然后：

- **✓ 收下这封回信**：保存，并自动记录回信的寄出和送达（路上的天数沿用来信的天数）；可以顺便发到聊天里，作为角色的消息
- **↻ 重新写**
- **丢弃**

你自己回复角色的来信时，在阅读视图里点「✎ 回复这封信」。

## 翻译

写信页的「🌐 翻译」：比如先用中文写草稿，再译成法语寄出去。

- 可以选目标语言（法语、英语、德语、意大利语、西班牙语、俄语、荷兰语、日语、中文，或者自己填）和文风：
  - **按写信年代的书信体**：参考写信日期，用那个年代的称呼、客套语和结尾。
  - 现代自然的说法。
  - 尽量保持原文的语气和句式。
- 段落保持一一对应。译文出来以后可以直接改，然后：
  - **替换正文**：原文会挪到这封信的备注里，书信语言自动改成目标语言。
  - **另存为译本**：原信不动，另存一封“译本”。

阅读外文信时，阅读页有「🌐 中文译文」，翻译给你看，不改原信；译文会缓存，下次直接显示。

## 从聊天记录找信

信件列表里的「📥 从聊天记录找信」：把当前聊天里已经写出来的信（比如角色在回复里写的一封信）逐字存进档案。

- **按格式识别**：找“称呼……结尾/署名”这样的段落，快，不调用 AI。会去掉引用符号 `>` 和斜体星号，不会把前后的叙述带进去。
- **AI 识别**：格式比较随意的信用这个。AI 只负责指出每封信从哪句开始、到哪句结束，**正文一律从聊天原文逐字截取**，AI 改写过的内容不会进档案；对不上原文的会被丢掉。
- 找到的信会列出来，可以改写信人、收信人、日期；档案里已经有的会标出来、默认不勾。
- 导入时可以记为“收信人已读”，这样他们会“记得”信里的内容。

## AI 接口

「⚙ 设置」→「AI 接口」。写回信、翻译、生成关键词、识别聊天里的信、推算剧情日期，都用这里设置的接口，可以和聊天用的 API 分开（比如聊天用好的模型，这些杂事用便宜的模型）。

- **跟随酒馆当前的 API**（默认）。
- **使用酒馆的连接配置**：先在酒馆的“API 连接”里设好一套接口并保存为连接配置，这里选它。不会切换你正在聊天用的接口。
- **自定义接口（OpenAI 兼容）**：填地址、密钥、模型（DeepSeek、硅基流动、OpenRouter、本地 Ollama 等都行），可以「获取模型列表」「测试连接」。请求经由酒馆服务端转发，不会有浏览器跨域问题。密钥保存在酒馆的设置文件里。

回信人就是当前聊天的角色时，写回信会带上角色卡设定和最近的剧情。

## 人物与文风档案

在「人物」页：

- **别名**：同一个人的不同叫法。角色卡叫「Vincent」、信里写「文森特」的话，一定要写成同一个人的别名，否则插件会认为这个角色什么信都没读过。
- **真实历史人物**：勾上之后，AI 会参照此人现存书信的口吻来写，同时被要求不要编造“名言”，也不要冒充真实信件里的原句。
- **参考的书信集**：比如“梵高书信（致提奥）”。
- **文风要点**：怎么称呼对方、怎么结尾、句子长短、常谈什么、对不同的人口吻有什么不同。
- **书信样本**：粘贴此人真实书信的片段，多段之间用单独一行 `---` 隔开。每次写回信时会随机挑几段给 AI 参考口吻，并提醒它只模仿口吻、不照抄内容。

「载入示例：文森特·梵高」会添加一份梵高的文风要点。这份要点是根据梵高书信公认的特点概括的，不含书信原文。想让回信更像本人，可以在「书信样本」里粘贴几段你手头的梵高书信。样本只保存在你自己的档案里。

## 聊天时自动注入信件

每次生成回复前，插件会扫描最近几条消息里的关键词，找出相关的信件段落，再按**视角角色**（默认是当前发言的角色，群聊时自动切换）和**剧情日期**过滤：

| 视角角色对这一段的了解 | AI 会看到 |
|---|---|
| 是写信人，或读过、听人念过、抄录过 | 这一段的**逐字原文** |
| 听人转述过 | 这一段的**一句话大意**（没有大意时，退化成下一行） |
| 只知道信存在 / 收到了还没读 | 一句「知道有这封信，但不知道内容」 |
| 没有任何记录 | **什么都没有** |

注入的文本会写明「信中所写是写信人当时的说法，不一定是事实」。正在聊天里被读的那封信不会被重复注入。

专家模式的「注入预览」能看到这一轮会注入什么、为什么命中、哪些被挡住以及原因。

## 数据存在哪

- 档案：`SillyTavern/data/default-user/user/files/epistolary_archive.json`
- 每次打开酒馆后第一次保存前，会把旧档案另存为同目录下的 `epistolary_archive.backup.json`
- 设置区有「导出档案 / 导入档案」，建议定期导出一份备份

档案在酒馆服务器的硬盘上，不在浏览器里，所以换浏览器、清缓存都不会丢。

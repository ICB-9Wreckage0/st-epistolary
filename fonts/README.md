# 随插件附带的字体

以下字体均为 SIL Open Font License 1.1 授权，允许随软件再分发。文件取自 Fontsource 打包的 Google Fonts 版本，只包含拉丁字母和拉丁扩展字母（英语、法语、德语等）。每款字体的授权全文见同目录下的 `LICENSE-*.txt`。

| 字体 | 文件 | 授权 |
|---|---|---|
| EB Garamond | `eb-garamond-*.woff2` | `LICENSE-eb-garamond.txt` |
| Allura | `allura-*.woff2` | `LICENSE-allura.txt` |
| Great Vibes | `great-vibes-*.woff2` | `LICENSE-great-vibes.txt` |
| Caveat | `caveat-*.woff2` | `LICENSE-caveat.txt` |

中文字体（霞鹜文楷、思源宋体 / Noto Serif SC、马善政楷书）不随插件附带，运行时从 jsDelivr 按需加载。
